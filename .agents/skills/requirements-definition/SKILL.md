# Requirements Definition Skill

## 절차 가이드라인
1. **문제 정의 (Problem Statement)**: 타깃 유저가 겪는 핵심 고통과 프로덕트 비전 명확화
2. **페르소나 및 유저 저니 맵 작성**: Mermaid journey 다이어그램을 활용한 엔드투엔드 여정 시각화
3. **MoSCoW 우선순위화**:
   - `Must Have`: 출시 필수 최소 기능
   - `Should Have`: 높은 비즈니스 가치를 가지나 우회 가능한 기능
   - `Could Have`: 여유 시 추가할 개선 기능
   - `Won't Have`: v1에서 제외할 기능
4. **산출물 작성**: `docs/templates/02_PRD_TEMPLATE.md` 구조에 맞춰 `docs/spec-writer/01_PRD.md` 저장
