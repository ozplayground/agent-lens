# Market & Reference Benchmark Skill

## 절차 가이드라인
1. **타깃 유사 서비스 3~5개 선정**: 글로벌 1~2개, 국내 1~2개, 버티컬 특화 1개
2. **선호 요인 (Best UX / Killer Features) 조사**: 앱스토어/G2/트위터 등 실제 사용자 긍정 리뷰 요인 분석
3. **불호 요인 (Pain Points / Pitfalls) 조사**: 사용자 이탈 유발 요인, 복잡한 정책, 에러 대응 불만 분석
4. **기회 영역 도출**: 2x2 매트릭스를 활용한 시장 기회(Opportunity Gap) 정의
5. **산출물 작성**: `docs/templates/01_MARKET_BENCHMARK_TEMPLATE.md` 구조에 맞춰 `docs/market-analyst/01_MARKET_BENCHMARK.md` 저장
