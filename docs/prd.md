# Product Requirement Document (PRD) - AgentLens v2.0

## 1. 제품 목적 및 비전
AgentLens는 단순한 뉴스 스크래퍼가 아닌, **AI 에이전트 기술·하네스(Harness)·MCP 생태계 전문 지능형 인텔리전스 플랫폼**입니다.
LLM을 통해 저품질 노이즈와 마케팅 글을 걸러내고, 개발자와 연구자에게 실질적인 기술 인사이트(3줄 요약, 핵심 시사점, 추출된 기술 스택)를 제공하며, 매일 아침 종합 브리핑과 대화형 심층 분석(Ask AI)을 지원합니다.

---

## 2. 핵심 기능 요구사항

### 2.1 LLM 기반 품질 게이트 & 큐레이션 (LLM Curation Gate)
- **품질 필터링**: 수집된 아티클의 기술 깊이(Tech Depth), 참신성(Novelty), 실용성(Actionability)을 점수화 (1~10점).
- **노이즈 컷오프**: 단순 광고, 클릭베이트, 비기술성 홍보 글 자동 제외.
- **하이 시그널 뱃지**: 8.5점 이상의 뛰어난 연구/릴리즈에는 `⭐️ Must Read` 또는 `🔥 High Signal` 뱃지 부여.

### 2.2 LLM 심층 기술 요약 및 합성 (Deep Synthesis)
- **3-Bullet Executive TL;DR**: 3개의 핵심 불릿으로 기술 요약.
- **Why It Matters (개발자를 위한 시사점)**: 에이전트 엔지니어가 왜 이 소식을 주목해야 하는지 1~2문장 인사이트 제공.
- **Tech Stack 자동 추출**: 본문에서 언급된 주요 모델, 프레임워크, 도구(예: `SWE-bench`, `LangGraph`, `MCP`, `DeepSeek-R1`, `vLLM` 등) 태그 자동 추출.

### 2.3 오늘의 AI 에이전트 브리핑 (Daily AI Intelligence Briefing)
- 지난 24시간 동안 수집된 하네스, MCP, 에이전트 소식 중 최상위 소식을 종합한 **일일 브리핑 리포트** 자동 생성.
- 마크다운 복사 및 파일 다운로드 지원.

### 2.4 대화형 심층 분석 & Ask AI (Interactive Deep-Dive)
- 카드 클릭 시 상세 뷰 모달 오픈:
  - 3줄 요약 + 개발자 시사점 + 기술 스택 배지.
  - **Ask AI 질문창**: 해당 기사/논문/릴리즈 내용에 대해 자유롭게 추가 질문("이 논문의 벤치마크 결과는?", "기존 SWE-bench와 차이점은?") 질의응답.

### 2.5 북마크 & 개인 보관함 (Reading List)
- 유용한 소식을 로컬/DB에 저장하고 `🔖 보관함` 탭에서 언제든 재확인.

### 2.6 듀얼 모드 LLM 엔진
- **기본 모드**: API 키 없이도 동작하는 내장 고성능 NLP 엔진 (문장 중요도 알고리즘, 엔티티 인식, 시사점 생성).
- **API 연동 모드**: `GEMINI_API_KEY`, `OPENAI_API_KEY` 등 설정 시 실시간 최신 LLM으로 자동 전환.

## 3. 카테고리 정의
1. **하네스 & 벤치마크 (`harness`)**: 에이전트 평가 하네스, 스캐폴딩, 샌드박스, 회귀 테스트
2. **MCP & Skills & Plugins (`mcp_plugins_skills`)**: Model Context Protocol, 도구 호출, 스킬
3. **에이전트 기술 (`agent_tech`)**: Multi-Agent 오케스트레이션, 메모리, 자율 워크플로우
4. **최신 AI 소식 (`ai_news`)**: 프론티어 LLM, 추론 모델, 글로벌/국내 연구 브레이크스루
