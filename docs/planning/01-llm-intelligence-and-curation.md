# [기획서] 01. 지능형 LLM 큐레이션 및 AI 인텔리전스 엔진

## 1. 기획 배경 및 목적
- **현상**: 단순 RSS/API 기반의 크롤링은 중복 기사, 광고/홍보성 글, 저품질 클릭베이트가 섞여 사용자가 유의미한 엔지니어링 지식을 빠르게 습득하기 어렵습니다.
- **목적**: 
  1. 수집 단계에서 LLM이 내용을 사전 심사하여 기술적 깊이(Tech Depth)와 실용성(Actionability)이 높은 **양질의 소식만 선별 수집**.
  2. 단순 본문 발췌를 넘어 **3줄 기술 요약**, **개발자를 위한 시사점(Why It Matters)**, **언급된 기술 스택/모델 추출**을 자동화.
  3. 매일 아침 AI 에이전트 동향을 한눈에 파악할 수 있는 **일일 AI 브리핑 리포트**와 각 소식에 대해 궁금한 점을 질문할 수 있는 **대화형 Ask AI 기능** 제공.

---

## 2. 핵심 기능 명세 (Feature Specifications)

### F-01. LLM 품질 평가 및 노이즈 필터링 게이트 (Quality Gate)
- **개념**: 기사 원문/요약 수집 시점에 LLM 평가기를 거쳐 수집 여부를 결정.
- **평가 지표**:
  - `tech_depth` (1.0~10.0): 구체적인 벤치마크, 아키텍처, 코드, 방법론이 포함되어 있는가?
  - `actionability` (1.0~10.0): 에이전트 개발자 및 연구자가 실제 워크플로우에 적용 가능한가?
  - `novelty` (1.0~10.0): 새로운 패러다임, 도구, 릴리즈인가?
- **품질 판정 정책**:
  - 총점 5.0 미만 (단순 할인 행사, 코인/투자, 마케팅 홍보, 10자 미만 제목): **수집 제외 (Drop)**
  - 총점 7.8점 이상: **`⭐️ High Signal` / `Must Read` 뱃지** 부여 및 상단 우선 노출

### F-02. 3줄 핵심 요약 (TL;DR) & 개발자 시사점 (Why It Matters)
- **3-Bullet TL;DR**:
  - 불릿 1: 기술적 핵심 주제 및 성격 (논문/오픈소스/도구 릴리즈)
  - 불릿 2: 연계된 핵심 모델 및 기술 스택
  - 불릿 3: 주요 결과, 벤치마크 점수 또는 핵심 해결 과제
- **Why It Matters (개발자 시사점)**:
  - "왜 이 소식이 지금 에이전트 엔지니어에게 중요한가?"에 대해 1~2문장으로 실질적 가치 요약.
  - 예: *SWE-bench 계열 회귀 테스트 자동화 파이프라인의 기준을 제시합니다.*

### F-03. 기술 스택 & 모델 엔티티 자동 추출 (Tech Stack Extractor)
- 본문에서 언급된 주요 기술 명사 자동 추출:
  - 모델: `Claude 3.7`, `GPT-4.5`, `DeepSeek-R1`, `Gemini 2.0`, `Llama 3.3` 등
  - 하네스/벤치마크: `SWE-bench`, `GAIA`, `WebArena`, `Docker Sandbox` 등
  - 프레임워크/도구: `Model Context Protocol (MCP)`, `LangGraph`, `CrewAI`, `FastMCP`, `Browser-Use` 등
- 카드 UI 상에 전용 모노스페이스 태그 뱃지로 렌더링.

### F-04. 오늘의 AI 에이전트 브리핑 (Daily AI Intelligence Briefing)
- 지난 24시간 동안 수집된 소식 중 High-Signal 및 인기 최상위 10건을 종합 분석.
- 구성:
  - 🌅 Executive Summary (1줄 총평)
  - 🎯 1. 하네스 & 벤치마크 하이라이트
  - 🔌 2. MCP & 도구·스킬 생태계 동향
  - 🤖 3. 에이전트 아키텍처 & 프론티어 AI 소식
  - 💡 4. 에이전트 개발팀을 위한 3대 Action Item
- 기능: 상단 배너 원클릭 열람, 마크다운 클립보드 복사, `.md` 파일 다운로드.

### F-05. 카드별 대화형 심층 분석 & 질의응답 (Interactive Ask AI)
- 카드 클릭 시 상세 Drawer/Modal 오픈.
- 기사 내용에 대해 사용자가 질문을 입력하면, 해당 기사의 맥락을 기반으로 AI가 즉시 답변:
  - 질문 예시: *"이 도구를 우리 에이전트 프로젝트에 어떻게 연동하나요?"*
  - 질문 예시: *"기존 버전이나 다른 프레임워크와의 차이점은 무엇인가요?"*

### F-06. 개인 지식 보관함 (Bookmarks)
- 유용한 아티클을 별표(⭐️) 클릭으로 보관.
- `localStorage` 기반 영속화 및 `🔖 보관함` 필터로 저장된 기사만 모아보기 지원.

## 3. 듀얼 모드 LLM 아키텍처 설계
1. **기본 모드 (Zero-Config Heuristic Engine)**:
   - API 키가 없어도 모든 사용자 환경에서 100% 정상 작동하는 내장 고성능 NLP 파이프라인.
   - 키워드 밀도, 텍스트 구조 분석, 도메인 사전 매핑을 통해 요약 및 시사점 즉시 생성.
2. **라이브 API 모드 (Live LLM Engine)**:
   - 사용자가 `GEMINI_API_KEY` 또는 `OPENAI_API_KEY`를 설정하면, Gemini 2.0 Flash 또는 GPT-4o-mini를 통해 실시간 생성형 합성으로 자동 전환.

---

## 4. 데이터 스키마 변경 계획
- `NewsItem` 모델 확장:
  - `tldr_bullets`: TEXT (JSON 직렬화된 3개 불릿 문자열)
  - `why_it_matters`: TEXT (개발자 시사점)
  - `tech_stack`: VARCHAR(500) (쉼표로 구분된 추출 엔티티)
  - `quality_score`: FLOAT (품질 점수 1.0~10.0)
  - `is_high_signal`: BOOLEAN (추천 하이 시그널 여부)

## 6. 사람(사용자) 액션 아이템 & 피드백 필요 사항
1. **API 키 설정 (선택 사항)**:
   - 외부 상용 LLM의 실시간 추론을 원하실 경우, 추후 `.env` 파일에 `GEMINI_API_KEY` 또는 `OPENAI_API_KEY`를 설정해 주시면 됩니다. (설정하지 않으셔도 내장 고성능 휴리스틱 엔진이 기본 탑재되어 100% 정상 작동합니다.)
2. **추가하고 싶은 도메인 키워드나 우선 관심사**:
   - 하네스, MCP 외에 특별히 추가로 집중 모니터링하고 싶은 프레임워크나 기업/주제가 있다면 피드백을 남겨주시면 분류 사전에 즉시 반영하겠습니다.
